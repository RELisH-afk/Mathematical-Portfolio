## Modeling and Analysis projects summaries 
Mathematical Modeling and Computational Projects

1. Differentiability Application — Numerical Analysis and Calculus

Course: Mathematics in AI
Technologies: HTML, CSS, JavaScript
Mathematical Concepts: Differentiability, continuity, limits, and numerical approximation

For this project, I developed an interactive application exploring the relationship between the difference quotient and the mathematical definition of differentiability. The application allows users to select mathematical functions, adjust an evaluation point, and change the step size used to approximate derivatives.

Using left- and right-hand difference quotients, the program estimates derivative values and compares them to determine whether a function is likely differentiable at a selected point. The application also displays graphical representations of functions, secant lines, and estimated tangent slopes.

I later expanded the project by improving the numerical restrictions used to classify differentiability, allowing smaller step sizes, and revising the mathematical explanations. This project helped strengthen my understanding of numerical approximation, mathematical limits, and the implementation of calculus concepts through programming.

2. Gradient Descent Investigation — Mathematical Optimization

Course: Mathematics in AI
Technologies: Python
Mathematical Concepts: Derivatives, gradients, optimization, and iterative numerical methods

This project explored gradient descent as an iterative mathematical method for locating the minimum of a function. Gradient descent uses derivative information to determine the direction in which a function decreases, allowing successive approximations to move toward a minimum.

I investigated both single-variable and multivariable functions, examining how starting points, learning rates, and repeated iterations influence the optimization process.

Using Python, I implemented numerical calculations demonstrating how gradient descent updates an initial estimate toward the minimum of a function. The results illustrated how calculus and programming can work together to solve optimization problems.

This investigation provided a foundation for understanding optimization methods used in artificial intelligence and machine learning, particularly how gradient information helps guide the minimization of an objective function.

3. Interactive Function Input Application — Programming Foundations

Course: Mathematics in AI
Technologies: HTML, CSS, JavaScript
Focus: Web development and user interaction

In an earlier programming assignment, I developed a basic interactive webpage that prompts users to enter an example of a mathematical function and displays their response.

Although this project did not involve numerical modeling, it introduced important programming concepts, including HTML structure, JavaScript functions, user input, and dynamically updating webpage content.

The experience provided a foundation for developing more advanced interactive applications, including my later Differentiability Application.
