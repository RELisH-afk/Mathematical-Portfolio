Mathematical Portfolio

Overview

This repository is a collection of mathematical explorations, projects, and studies that I have completed throughout my academic coursework and personal learning. Its purpose is to document my growing mathematical knowledge, programming experience, and application of mathematical concepts to computational problems.

Repository Organization

Reports: Contains written reports, mathematical investigations, and overviews of the projects included in this repository.

Portfolio: Provides an overview of my mathematical knowledge, technical skills, and academic experience.

Differentiability App: An interactive application developed to explore the difference quotient and its relationship to the mathematical definition of differentiability. The application uses numerical approximations to investigate whether a function is differentiable at a selected point.

Apps (Coming Soon): As I develop additional mathematical applications, I plan to consolidate them into a dedicated directory. Currently, the Differentiability App is the only completed application.

Future Development

I intend to continue expanding this repository with additional mathematical investigations, programming projects, and computational applications as I progress through my studies and independent learning.
